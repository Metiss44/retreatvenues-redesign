# RetreatVenues - Redesign Mockups

Static redesign mockups for RetreatVenues pages.

## Files

- `index.html` - standalone HTML mockup of the redesigned `List Your Venue` page.
- `home-redesign-v1.html` - standalone HTML mockup of the redesigned homepage.
- `assets/Pool.png` - hero image used in the mockup.
- `docs/client-preview.pdf` - PDF preview without the website menu/header for client review.
- `docs/home-elementor-plan.md` - section-by-section Elementor build plan for the homepage.
- `snippets/stats-counter.html` - optional Elementor HTML snippet for animated stats.

## Design Direction

- Primary violet: `#705463`
- Hover violet: `#5C4351`
- Main beige: `#EDE6E2`
- Light cream: `#FBF7F4`
- Main text: `#2F292C`
- Secondary text: `#756B70`
- Accent label: `#B28A58`
- Font direction: Inter or Roboto, sans-serif only.

## WordPress / Elementor Notes

This mockup is intended as a visual and content reference before rebuilding the page in Elementor.

Recommended workflow:

1. Duplicate the current `List Your Venue` page in WordPress.
2. Work only on the duplicated V2 page.
3. Rebuild the page section by section in Elementor.
4. Save important sections as Elementor templates.
5. Check desktop, tablet, and mobile before replacing the live page.

Avoid changing global WPRentals or Elementor settings during the first rebuild unless the impact on the rest of the site has been checked.
